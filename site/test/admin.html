Q&A

챗봇은 이 Q&A만 근거로 답합니다. 질문이 여기 있는 것과 비슷하면 모델을 쓰지 않고 이 답을 그대로 보여 줍니다. 키워드는 쉼표로 나눠 적으세요.

      적용 후 위의 ‘변경 저장’을 눌러야 서버에 저장됩니다.

      응답 문구

      규칙에 걸렸을 때 챗봇이 보여 주는 고정 문구입니다. 이 문구들은 모델을 쓰지 않습니다.

      규칙

      이상한 사용을 막는 기준입니다. 경고가 쌓이면 대화를 종료하고, 같은 접속에서 종료가 반복되면 24시간 막습니다.

      경고가 쌓이는 경우

      • 의미 없는 글자(같은 글자 반복, 자음·모음만, 기호 위주)
      • 지침 · 프롬프트를 알아내거나 규칙을 무시하게 하려는 질문 (문장 패턴으로 먼저 거르고, 모델도 한 번 더 판단)
      • 사이트와 관련 없는 질문 (모델 판단)
      • 같은 질문을 허용 횟수보다 많이 반복
      • 욕설 · 일부러 길게 답하게 만드는 요청 등 정상 이용으로 보기 어려운 질문 (모델 판단)

      대화 기록

      최근 대화 300개. 줄을 누르면 내용을 봅니다. 대화 기록은 30일 뒤 자동으로 지워집니다.

      마지막이름소속질문경고상태

      대화 시작 알림
